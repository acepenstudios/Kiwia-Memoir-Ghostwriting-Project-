# Memoir & Ghostwriting Project
### Ace Pen Studio

**Preserving a life. Giving it a story.**

This repository supports the development of a bespoke memoir and ghostwriting engagement facilitated by Ace Pen Studio.

The project begins with a discovery process designed to understand the Interview Subject's life experiences, expectations, preferred approach to storytelling and the intended purpose of the book.

### About the project

Ace Pen Studio approaches each memoir as an individual editorial engagement. The writing process is shaped around the person whose story is being documented, the experiences they wish to share and what they hope the finished book will achieve.

### About Ace Pen Studio

Ace Pen Studio is a consultancy studio and creative hub where stories are articulated and visions executed.
